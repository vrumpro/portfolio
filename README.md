# Портфолио Алексея Пашкова

Vue 3 + Vite, отдельный проект D:\Projects\portfolio.

- SOKOLOV — карточка товара.
- Wikkeo — магазин и карточка товара.
- inDrive — выбор курьера.

Запуск: `npm.cmd start`, http://127.0.0.1:5173.
Сборка: `npm.cmd run build`.

На главной — объёмные логотипы на цветных подложках, созданные по материалам пользователя в перспективной галерее. Управление колесом, свайпом, клавиатурой и переключателями. На мобильном галерея горизонтальная. При открытии кейса логотип выравнивается на белой обложке; стрелка вниз ведёт к задаче. При прокрутке работает параллакс, а в конце на desktop плавно открывается следующий кейс. Стрелка внизу заполняется за пять секунд перед сменой проекта; прокрутка назад сбрасывает отсчёт. На мобильном отсчёт запускается нажатием. Шрифты: Manrope для заголовков и Inter для текста. Хедер содержит ссылку на Телеграм. Футера и полноэкранного просмотра нет.

VERSTA и Atlas убраны из активных страниц. Исходные материалы сохранены.

Источники: assets/logos/sources.json, assets/sources.json, assets/fonts/reference-sources.json. Архитектура и результаты проверок — docs/ARCHITECTURE.md и docs/CURRENT_STATE.md.
